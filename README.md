# Working Island World Generation in Vanilla Minecraft 26.3

I could not find much information online about world generation data packs, so I decided to show you how it works.

# Here are the steps to create a data pack like this:

1. Create a folder and name it anything you want.
2. In the folder create a file called pack.mcmeta.
3. Now create a folder called "data" in the same folder as the pack.mcmeta.
4. Under data, make another folder called "minecraft".
5. Under minecraft, create a folder and name it "worldgen".
6. In worldgen create a folder and named "noise_settings".
7. Finally, Under noise_settings, create an overworld.json.

Look at the overworld.json file to see the contents of it.
